The DelTech MUN platform runs everything around a conference: the public website,
delegate registration, the portfolio matrix, allotments, payments, check-in at the
door, the Dispatch, live quizzes, and the society's own recruitment cycles.

These docs explain all of it. Every page is written for a specific reader, assumes
no prior knowledge of the system, and links to the pages either side of it.

## How these docs are organised

Pages are short and single-topic on purpose. Rather than one long "delegate guide"
you will find one page per step, so you can be sent a link to exactly the thing you
are stuck on. Longer explanations sit behind links instead of being inlined, and
anything with a screen attached to it has a screenshot.
