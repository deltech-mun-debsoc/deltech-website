## Four things that will surprise you

**Middleware is called `proxy.ts`.** Next 16 renamed it. It lives at `src/proxy.ts`, exports
`proxy`, and its matcher covers only `/admin`, `/write`, `/dashboard`, `/account` and
`/recruitment`. The whole public site never touches it.

**There is no test framework.** No Jest, no Vitest, no Playwright. There are thirty-two
standalone `node:assert` scripts under `scripts/`, run by `npm run check`. See
[testing](/docs/developers/testing).

**No component may contain a hardcoded string, and no file may contain an em dash.** Both
are enforced in CI. See [the strings rule](/docs/developers/strings).

**shadcn here sits on Base UI, not Radix.** The style is `base-nova`. See
[UI components](/docs/developers/components).

## External services

| Service | Used for | Degrades how |
|---|---|---|
| **PostgreSQL** (Supabase-hosted) | All relational data | Hard dependency |
| **Resend** | All outbound email | Failures are logged; the action still succeeds |
| **Razorpay** | Card, netbanking and UPI payments | Falls back to UPI QR or a static link by config |
| **Supabase Realtime** | Live quiz only | Returns null when unconfigured rather than crashing |
| **S3** | Blog images | Throws a typed "not configured" error |
| **Groq** | Import column suggestions | Optional |

Nothing except Postgres is required for the app to boot, which is what makes CI able to
build without any credentials.
